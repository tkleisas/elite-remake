# Elite Remake 8x8 font
#
# An original monospace bitmap font drawn for this remake, in the style of the BBC Micro's
# eight-by-eight character cells: the glyph sits in the top seven rows and the bottom row is
# reserved so that letters with descenders (g, j, p, q, y) can drop below the baseline. Each
# character occupies a cell eight pixels wide, with the eighth column usually left clear as a
# gap.
#
# Format:
#   <code> <name>          a header line, with the character's ASCII code
#   ........               eight rows of eight pixels; '#' is on, '.' is off
#
# This file is embedded into EliteRemake.Data and parsed by BitmapFont.
